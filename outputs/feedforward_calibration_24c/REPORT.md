## 更新曲线

将实测总占空比（包含积分补偿）换算为22°C参考点：

```
U22 = U24 × (目标−22)/(目标−24)
40°C: 325.8120‰
60°C: 565.6990‰
F22 = clip(11.99435 × (目标−12.83620), 0, 850)
F = clip(F22 × max(目标−室温,0)/(目标−22), 0, 850)
```

两个参数替换Core/Inc/separation_pid.h中的旧20.13和34.65，积分、P/D参数保持原值。24°C室温下40°C前馈从95.73‰提高至289.61‰，60°C从483.44‰提高至535.93‰。主要修正是40°C基础功率不足。

40–60°C之间为两点插值；区间外和其它室温为估计，尚未验证。实测温度均值略高于目标（40.1009/60.0442°C），拟合将其视为对应目标附近的保温点，存在小幅偏差。
