# 60°C 积分分离 PID 优化

沿用四线半双工通信和 STM32 本地 PID，PID 周期 1 秒，加热 PWM 10 Hz。
反馈取两温度传感器中较高值。所有试验有时限，全程读取状态；超过 63°C、传感器无效、故障或控制状态异常时提前停止，每轮结束发送 STOP。

## 基准轮

参数：Kp=100、Ki=1、Kd=600、积分分离阈值=6°C，输出单位为千分比。
目标 60°C，初始约 35.9°C，计划 900 秒。
文件：target60_trial01_kp100_ki1_kd600_sep6.csv。

本轮及后续参数结论待实测完成后填写。

## 基准轮中断与核验

首轮在约 445 秒时因风扇反馈失效提前结束，未完成 60°C 恒温阶段。最高有效温度 59.54°C，异常前输出 728/1000，尚无超调。不能用此轮证明 60°C 稳定性，也不能据此宣布参数已优化。

原始历史显示 STM32 tick 1338698 ms 时 fan_running=1、output=728；下一帧 1339698 ms 变为 fan_running=0、fault=1、output=0、running=0。STOP 随后确认应用。

实机只读 SWD 核验 GPIOA_IDR=0x0000df58，PA8 bit8=1（高）；GPIOA_CRH=0x88844448，PA8 配置字段=8（上/下拉输入）。这与 LOCK 高电平故障报告一致，但不能单靠该反馈判定是风扇停转、供电、接线还是信号线问题，需现场确认。

原始数据：target60_trial01_gateway_history.csv；上位机采样：target60_trial01_kp100_ki1_kd600_sep6.csv；统计：metrics_60C.json。

当前保留 Kp=100、Ki=1、Kd=600、分离阈值6°C。待风扇运行反馈恢复并排除异常原因后，继续完整基准轮及改进参数对比。

## 风扇恢复后重新测试

用户确认风扇及电源正常，随后 API 实测 fan_running=true、fault=0，设备冷却至约27.5°C。重新开始完整基准轮，参数保持100/1/600、分离阈值6°C，目标60°C，最长1200秒，到时或异常自动停机。
数据：target60_trial02_baseline_recovery.csv；命令序号14。

后续试验因短暂HTTP连接异常中断，监测工具改为复用直连HTTP连接、5秒超时、单次重试，连续错误仍停机。第四段试验进行中用户改为50°C测试，已正常中止并确认输出关闭。60°C未完成恒温参数比较，不再继续该目标。
