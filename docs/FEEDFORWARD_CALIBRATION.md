# 前馈校准步骤与当前结果

2026-09-17已在用户提供的24°C室温下完成40°C、60°C两段校准。详细数据见[实验报告](../outputs/feedforward_calibration_24c/REPORT.md)。

当前公式（输出千分比）：
```
F22 = clip(11.99435 × (target − 12.83620), 0, 850)
F = clip(F22 × max(target − ambient,0)/(target − 22), 0, 850)
```
24°C室温：40°C前馈28.9611%，60°C前馈53.5925%。

1. 固定负载、风量和电源，输入实际箱外室温，关闭湿度暂停。
2. 保持PID开启，从冷机升至40°C、恒温，再升至60°C、恒温。
3. 每段至少在±0.2°C内保持5分钟；检查温度和输出趋势，仍漂移则延长。
4. 取末120秒实际总占空比的时间加权平均，不剔除积分输出。该总输出估计保温需要的功率。
5. 各点按U22=U×(目标−22)/(目标−室温)归一化。两点计算slope=(U22_2−U22_1)/(T2−T1)，offset=T1−U22_1/slope。
6. 修改源码参数、运行测试、编译刷写，再验证冷启动到温时间、超调和恒温波动。不要把旧固件的实验当成新参数的验证。

两点仅约束40–60°C。其它目标与环境需要补充标定。温度偏高/偏低不能单独确定前馈是否正确，积分会掩盖基线误差。
